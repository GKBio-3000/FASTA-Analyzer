# 🧬 FASTA Analyzer with UI & Graphs

A Python-based bioinformatics application that analyzes DNA sequences from FASTA files using a simple graphical interface and visualizes sequence statistics with graphs.

---

## 🚀 Features

* 📂 Upload and read FASTA files
* 🧬 Parse multiple DNA sequences
* 📏 Calculate sequence length
* 📊 Compute GC content (%)
* 📈 Visualize:

  * Sequence length distribution (bar chart)
  * GC content distribution (bar chart)
* 🖥️ User-friendly GUI built with Tkinter

---

## 🛠️ Technologies Used

* Python
* Tkinter (GUI)
* Matplotlib (Data Visualization)

---

## 📦 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/fasta-analyzer.git
cd fasta-analyzer
```

### 2. Install dependencies

```bash
pip install matplotlib
```

---

## ▶️ How to Run

```bash
python app.py
```

---

## 📂 Input Format (FASTA)

The program accepts standard FASTA files:

```
>seq1
ATGCGTA
>seq2
TTGCAA
```

---

## 📊 Output

After uploading a FASTA file, the application will:

* Display:

  * Total number of sequences
  * Length of each sequence
  * GC content (%)
  * AT content (%)
* Generate graphs:

  * Sequence length bar chart
  * GC content bar chart
  * AT content bar chart
